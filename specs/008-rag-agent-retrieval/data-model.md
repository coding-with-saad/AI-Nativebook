# Data Model: RAG Agent with Retrieval Pipeline

**Feature Branch**: `008-rag-agent-retrieval` | **Date**: 2026-02-27 | **Plan**: [specs/008-rag-agent-retrieval/plan.md]
**Spec**: [specs/008-rag-agent-retrieval/spec.md]

## Entities

### User Query

-   **Description**: The natural language question submitted by the user.
-   **Fields**:
    -   `text`: String - The actual query string.
    -   `timestamp`: Datetime - Time when the query was received.

### Book Embedding

-   **Description**: The vector representation of a book chunk, stored in Qdrant.
-   **Fields**:
    -   `vector`: Array of Floats - The embedding vector.
    -   `text_chunk_id`: String - Foreign key to the associated Text Chunk.
    -   `source_book_id`: String - Identifier for the original book.
    -   `metadata`: JSON - Additional metadata (e.g., page number, chapter).

### Text Chunk

-   **Description**: A segment of text from a book.
-   **Fields**:
    -   `id`: String - Unique identifier for the text chunk.
    -   `content`: String - The raw text content of the chunk.
    -   `source_book_id`: String - Identifier for the original book.
    -   `start_char`: Integer - Starting character index in the original book.
    -   `end_char`: Integer - Ending character index in the original book.
    -   `embedding_status`: Enum (PENDING, EMBEDDED, FAILED) - Status of embedding generation.

### Retrieved Context

-   **Description**: A collection of `top_k` relevant text chunks returned by Qdrant.
-   **Fields**:
    -   `chunks`: Array of Text Chunk - List of relevant text chunks.
    -   `relevance_scores`: Array of Float - Similarity scores for each chunk.

### AI Agent Prompt

-   **Description**: The input provided to the OpenAI agent, including the query and retrieved context.
-   **Fields**:
    -   `system_instructions`: String - Static or dynamic instructions for the agent.
    -   `user_query`: String - The user's original question.
    -   `context_sections`: Array of String - Formatted retrieved context chunks.
    -   `formatting_style`: Enum (XML_TAGS, TRIPLE_QUOTES) - Style used for context injection.

### Agent Answer

-   **Description**: The response generated by the AI agent.
-   **Fields**:
    -   `text`: String - The generated answer.
    -   `sources`: Array of String - Identifiers or references to the sources used (e.g., `text_chunk_id`, `source_book_id`).
    -   `hallucination_check_status`: Enum (PASSED, FAILED, N/A) - Result of the grounding check.

### Log Entry

-   **Description**: Record of a query and its processing, primarily for monitoring and debugging.
-   **Fields**:
    -   `query_id`: String - Unique ID for each query session.
    -   `user_query_text`: String - The user's original query.
    -   `retrieved_chunk_ids`: Array of String - IDs of chunks retrieved from Qdrant.
    -   `agent_answer_text`: String - The final answer generated by the agent.
    -   `response_time_ms`: Integer - Total time taken to process the query.
    -   `timestamp`: Datetime - Time when the log entry was created.
    -   `status`: Enum (SUCCESS, RETRIEVAL_FAILED, AGENT_FAILED, HALLUCINATION_DETECTED) - Outcome of the query processing.

## Relationships

-   **User Query** triggers the retrieval of **Book Embeddings** and **Text Chunks**.
-   **Book Embedding** is a vector representation of a **Text Chunk**.
-   **Retrieved Context** is composed of multiple **Text Chunk** entities.
-   **AI Agent Prompt** incorporates **User Query** and **Retrieved Context**.
-   **Agent Answer** is generated from **AI Agent Prompt** and references **Text Chunk** entities as sources.
-   **Log Entry** records data from **User Query**, **Retrieved Context**, and **Agent Answer**.
