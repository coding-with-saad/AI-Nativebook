# Data Model: RAG Frontend Integration

**Branch**: `009-rag-frontend-integration` | **Date**: 2026-03-02 | **Spec**: [spec.md](spec.md)

This document outlines the data structures used in the RAG frontend integration feature.

## Query

- **Description**: Represents a user's question submitted through the chat interface.
- **Attributes**:
  - `question` (string): The raw text of the user's query.

## Response

- **Description**: Represents the answer generated by the RAG agent.
- **Attributes**:
  - `answer` (string): The Markdown-formatted answer to the user's query.
  - `sources` (array of SourceReference): A list of sources used to generate the answer.

## SourceReference

- **Description**: Represents a single source document or section referenced in the answer.
- **Attributes**:
  - `path` (string): The path to the source file.
  - `heading` (string, optional): The specific heading or section within the source file.
  - `page` (integer, optional): The page number, if applicable.
